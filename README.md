# 二狗梅花易数 APP

Android 梅花易数应用：数字占 / 时间占 / 字占，三法起卦；本卦、互卦、变卦与动爻解卦。  
另含八字排盘（农历/阳历、真太阳时）、短信登录与近 7 天算卦历史。

## 功能简介

- **数字占**：三个数字起卦，可叠加时辰
- **时间占**：按当前年月日时自动成卦
- **字占**：按汉字笔画拆分上下卦
- **解卦**：本卦 / 互卦 / 变卦与动爻
- **八字**：农历/阳历、地区经度校正真太阳时
- **我的**：短信登录、算卦历史（保留 7 天）
